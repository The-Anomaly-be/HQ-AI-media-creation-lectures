Introduction aux modèles locaux : Qwen Image 2.1

Chaque composant et paramètre a une fonction précise que nous allons décortiquer ensemble dans ce guide clair et visuel.

1

La vue d'ensemble

À lire en premier

Qwen Image 2.1 ne peint pas comme vous le feriez. Il commence avec un écran de bruit statique pur et le nettoie petit à petit jusqu'à ce qu'il ressemble à votre prompt. Le même modèle accomplit deux tâches : créer une image à partir de mots, ou modifier une image que vous lui fournissez.

Vous

Prompt

Vos mots, plus une ou plusieurs images si vous faites de l'édition.

Le Lecteur

Encodeur texte

Lit le prompt, regarde vos images, et traduit tout en nombres. (Load CLIP)

L'Artiste

Modèle de diffusion

Nettoie le bruit guidé par le lecteur. Presque toute l'attente est ici.

Le Décompresseur

VAE

Transforme la version compressée en vrais pixels, transparence incluse.

Résultat

Fichier PNG

Jusqu'à 2048x2048, avec un fond transparent si demandé.

Une étape (step) est une passe de nettoyage. Plus il y a de passes, plus le résultat est propre et détaillé, mais plus l'attente est longue.

2

Ce qu'il fait

Un modèle, cinq tâches

Il n'y a pas de commutateur de mode. Ce que vous branchez et ce que vous demandez détermine la tâche.

TâcheVous lui donnezCe qu'il en faitÀ utiliser quand...
Text to image Un prompt. Rien d'autre. Invente toute l'image. Exceptionnellement doué pour générer du texte lisible dans l'image (panneaux, affiches). Vous partez de rien, ou vous avez besoin que les mots dans l'image soient correctement orthographiés.
Image edit Un prompt et 1 image (image_1). Modifie ce que vous demandez et laisse le reste intact. Conserve la taille et la forme originale. Vous aimez une image mais voulez changer un détail : tenue, fond, lumière, ou retirer un objet.
Edit avec références Un prompt et jusqu'à 10 images. image_1 est modifiée. Les autres sont des éléments à emprunter : visage, vêtement, style. Vous voulez combiner des choses. "Mets la chemise de <image2> sur la personne de <image1>."
Image Transparente Un prompt enveloppé dans une phrase précise (voir Slide 10). Génère le sujet sur un fond véritablement transparent (format RGBA). Vous avez besoin d'un calque détouré (logo, sticker, photo produit) à superposer ailleurs.
Background removal Une image et le prompt "Remove the background...". Renvoie votre sujet avec le fond rendu transparent. Vous avez déjà l'image et voulez uniquement le détourage.
3

Les Pièces du Puzzle

À quoi servent les fichiers

Un workflow charge 3 fichiers de modèles principaux.

Modèle diffusion Le Modèle

a.k.a: checkpoint, UNet, DiT

Son rôle : Crée l'image. C'est LE modèle.

Sa charge : Travaille à chaque étape (définit la vitesse). Sa petite taille le rend facile à utiliser sur des cartes moyennes.

Encodeur texte Le Lecteur

a.k.a: CLIP / type: qwen_image

Son rôle : Lit votre prompt/images, transmet au modèle image des nombres.

Sa charge : Modèle massif (Qwen3-VL, 8B paramètres), plus gros que le modèle image. S'exécute 1 fois au début.

VAE Décompresseur

field: vae_name

Son rôle : Transforme le résultat compressé en vrais pixels, et compresse vos images en entrée.

Spécificité : Gère 4 canaux (le 4ème est la transparence). Utilisez qwen_image_2.1_vae_bf16.

Pièces optionnelles (dans les templates)

Prompt enhancer (Le Réécrivain) : Un 2ème modèle qui réécrit votre prompt en détail. Coûte 6-9 Go de VRAM. Désactivez-le au début.
Qwen Image 2.1 Cache (Accélérateur d'édition) : Calcule la partie redondante d'une édition une seule fois. (Laissez dtype sur int8).

Décoder les noms

Comprendre les lettres
qwen_image_ 2.1_ int8_convrot .safetensors

Le nombre magique (Les Formats)

Un modèle est une liste géante de nombres. Ces lettres indiquent le nombre de bits utilisés pour stocker chaque nombre. Moins de bits = fichier plus petit, rentre mieux sur votre carte, résultat légèrement moins précis.

bf1616 bits par nombre. L'original, la qualité maximale, le plus gros fichier.
int88 bits par nombre. Environ la moitié de la taille du bf16 original.
convrotL'astuce qui rend le int8 très qualitatif (mélange avant arrondissement).
w4a84-bit pour le stockage, 8-bit actif. Encore plus petit que le int8.

Plus petit n'est pas automatiquement meilleur. Un plus petit fichier n'aide que pour rentrer sur la carte graphique. Chaque baisse de bits sacrifie un peu de précision. Sur une carte 16 Go, ce lot par défaut (int8) rentre parfaitement. La vraie "amélioration" à tester si vous avez la mémoire est le modèle de diffusion en bf16.

Ne modifiez qu'une seule chose à la fois avec la graine (seed) fixée, sinon vous ne saurez pas ce qui a fait effet.

Matériel et Offloading

Un modèle très accessible

L'établi

VRAM (ex: 16 Go)

Mémoire de la carte graphique. Ce qui est dessus s'exécute à pleine vitesse. Paramètre crucial.

L'étagère

RAM (ex: 32 Go)

Mémoire du PC. Ce qui ne rentre pas sur l'établi attend ici en file indienne.

Le Va-et-vient

Offloading

ComfyUI déplace automatiquement les morceaux entre l'étagère et l'établi. Ça coûte du temps.

Les chiffres : L'ensemble par défaut pèse environ 16 Go au total. Ils ne sont pas tous sur la carte en même temps. Ils chacun leur tour. Sur 16 Go, rien ne déborde. Sur 12 Go, ça passe toujours. Sur 8 Go, le Lecteur ne rentre pas, c'est là qu'intervient la version w4a8 du lecteur.

Trop lent ou Out of Memory ? Leviers dans l'ordre :

  1. Baissez les Mégapixels : Revenez à 1 MP.
  2. Baissez les Steps : 25, ou utilisez Turbo (8 steps).
  3. Désactivez le Prompt Enhancer : C'est un modèle entier supplémentaire à charger.
  4. Prenez un plus petit Lecteur : qwen3vl_8b_w4a8 (5.9 Go) au lieu du int8.
  5. Réduisez le Cache d'Édition : Mettez dtype sur int8 sur le nœud Qwen Cache.
  6. Libérez le PC : Fermez toutes les autres applications.

Dépannage et Lexique

Comprendre les erreurs

Les Erreurs Courantes

Boîtes rouges à l'ouverture
Nœuds personnalisés manquants ou ComfyUI pas à jour. Mettez à jour puis utilisez ComfyUI Manager.
"Value not in list"
Le fichier n'est pas dans le bon dossier, ou n'a pas le nom exact.
"CUDA out of memory"
La VRAM de la carte est pleine. Baissez la résolution, testez les étapes Slide 8.
Plante APRES la fin de l'étape
Souvent le VAE qui manque de mémoire pour décompresser l'image finale. Baissez la résolution.
Le PC entier fige ou rampe
La RAM PC est pleine. Fermez Chrome, utilisez de plus petits modèles.

Mots Techniques

La Plomberie
CUDA / PyTorch : PyTorch est le moteur mathématique. CUDA est la couche NVIDIA pour la carte graphique. Vous n'y touchez pas. cu130 dans les logs veut juste dire la version CUDA.
Une extension
Custom Node : Chaque boîte à l'écran est un "nœud". Un Custom Node est une boîte de la communauté. Qwen 2.1 n'en a besoin d'aucun (intégrés natifs).
Un pack très populaire
rgthree : Nœuds de confort (stacker de LoRA, interrupteurs...).

Premier lancement

Un point de départ fiable

Faites fonctionner une image simple avec la configuration officielle avant de tenter des choses complexes.

La Recette

  1. Mettez ComfyUI à jour : Le support de Qwen 2.1 est récent.
  2. Ouvrez le Template intégré : Menu Workflow > Browse Templates > Cherchez "Qwen Image 2.1" > Prenez Text to Image.
  3. Placez les fichiers : L'ensemble exact listé en Slide 6, dans leurs bons dossiers.
  4. Laissez les réglages par défaut : 1 MP, 25 steps, CFG 1, euler, simple.
  5. Lancez ! Le premier rendu est lent car il doit charger les gros fichiers.
  6. Puis, tentez une édition : Ouvrez le template "Image Edit", il utilise les 3 mêmes fichiers.

Exercices

1) Créer une image d'un lapin avec un chapeau: Décrivez de manière détaillée (l'apparence du sujet, le décor, l'éclairage, le type de prise de vue, le style - photo, dessin animé, manga, ...). Pour du texte dans l'image, mettez les mots exacts "entre guillemets".

2) Editez cette image: Demandez-lui de transformer le chapeau en un autre objet en utilisant l'image créée comme image de référence. Allez chercher le bon workflow dans les modèles si nécessaire.

3) Créez un prop avec fond transparent: Pour les besoins d'un film, vous avez besoin d'un impact de balle de gros calibre sur un mur de brique, créez un prop de petite taille (512x512) avec un fond transparent qui correspond.

Prompt transparent exact :

This is an RGBA format image with transparency. [votre description ici]. The image has an alpha channel and a transparent background.
