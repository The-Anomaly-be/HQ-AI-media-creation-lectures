Introduction to Local Image Models: Qwen Image 2.1

Every component and setting has a specific function that we will dissect together in this clear and visual guide.

1

The Big Picture

Read this first

Qwen Image 2.1 does not paint the way you would. It starts with a screen of pure static and cleans it up a little at a time until it looks like your prompt. The same model does two jobs: making a picture from words, or changing a picture you give it.

You

Prompt

Your words, plus one or more pictures if you are editing.

The Reader

Text Encoder

Reads the prompt, looks at your pictures, and turns it all into numbers. (Load CLIP)

The Artist

Diffusion Model

Cleans up the static guided by the reader. Nearly all of your wait is here.

The Unpacker

VAE

Turns the compressed version back into real pixels, transparency included.

Result

PNG File

Up to 2048x2048, with a transparent background if requested.

2

What it does

One model, five jobs

There is no mode switch. What you plug in and what you ask for decides the job.

JobYou give itWhat it does with itReach for it when...
Text to image A prompt. Nothing else. Invents the whole picture. Unusually good at generating readable text inside the image (signs, posters). You are starting from nothing, or you need words in the picture to be spelled correctly.
Image edit A prompt and 1 picture (image_1). Changes what you ask for and leaves the rest alone. Keeps the original size and shape. You like a picture but want to change a detail: outfit, background, lighting, or remove an object.
Edit with references A prompt and up to 10 pictures. image_1 is edited. The others are elements to borrow: face, clothing, style. You want to combine things. "Put the shirt from <image2> on the person in <image1>."
Transparent Image A prompt wrapped in a specific sentence (see Slide 10). Generates the subject on a truly transparent background (RGBA format). You need a cut-out layer (logo, sticker, product photo) to overlay elsewhere.
Background removal One picture and the prompt "Remove the background...". Returns your subject with the background made transparent. You already have the picture and only want the cut-out.
3

The Pieces of the Puzzle

What the files are for

A workflow loads 3 main model files.

Diffusion Model The Artist

a.k.a: checkpoint, UNet, DiT

Its job: Makes the picture. This is THE model.

Its load: Works on every step (sets the speed). Its small size makes it easy to run on mid-range cards.

Text Encoder The Reader

a.k.a: CLIP / type: qwen_image

Its job: Reads your prompt/images, and hands numbers to the image model.

Its load: Massive model (Qwen3-VL, 8B params), bigger than the image model. Runs once at the start.

VAE The Unpacker

field: vae_name

Its job: Turns the compressed result into real pixels, and compresses your input images.

Specificity: Handles 4 channels (the 4th is transparency). Use qwen_image_2.1_vae_bf16.

Optional parts (in templates)

Prompt enhancer (The Rewriter): A second model that rewrites your prompt in detail. Costs 6-9 GB of VRAM. Leave it off at first.
Qwen Image 2.1 Cache (Edit Accelerator): Calculates the redundant part of an edit once. (Leave dtype on int8).

Decoding Names

Understanding the letters
qwen_image_ 2.1_ int8_convrot .safetensors

The Magic Number (Formats)

A model is a giant list of numbers. These letters indicate how many bits are used to store each number. Fewer bits = smaller file, fits better on your card, slightly less accurate result.

bf1616 bits per number. The original, max quality, biggest file.
int88 bits per number. About half the size of the original bf16.
convrotThe trick that makes int8 high quality (shuffling before rounding).
w4a84-bit for storage, 8-bit active. Even smaller than int8.

Hardware and Offloading

A very accessible model

The Workbench

VRAM (e.g., 16 GB)

Graphics card memory. Whatever is on it runs at full speed. This is the crucial bottleneck.

The Shelf

RAM (e.g., 32 GB)

PC memory. Whatever doesn't fit on the workbench waits here in line.

The Shuffle

Offloading

ComfyUI automatically moves pieces between the shelf and workbench. It only costs time.

The numbers: The default set weighs about 16 GB in total. They do not all sit on the card at once. They take turns. On 16 GB, nothing spills over. On 12 GB, it still fits. On 8 GB, the Reader doesn't fit, which is where the w4a8 version of the reader comes in.

Too slow or Out of Memory? Pull these levers:

  1. Lower Megapixels: Drop back to 1 MP.
  2. Lower Steps: 25, or use Turbo (8 steps).
  3. Turn off Prompt Enhancer: It's a whole extra model to load.
  4. Use a smaller Reader: qwen3vl_8b_w4a8 (5.9 GB) instead of int8.
  5. Shrink Edit Cache: Set dtype to int8 on the Qwen Cache node.
  6. Free the PC: Close all other applications (browser tabs, etc.).

Troubleshooting and Glossary

Understanding errors

What an error is telling you

Red boxes on opening
Missing custom nodes, or ComfyUI needs an update. Update first, then use ComfyUI Manager.
"Value not in list"
The file is not in the correct folder, or doesn't have the exact expected name.
"CUDA out of memory"
The card's VRAM is full. Lower resolution, follow Slide 8 steps.
Dies AFTER the last step
Usually the VAE running out of memory to unpack the final image. Lower resolution.
Whole PC freezes or crawls
PC RAM is full. Close Chrome, use smaller model versions.

Technical Words

The Plumbing
CUDA / PyTorch: PyTorch is the math engine. CUDA is the NVIDIA layer for the graphics card. You never touch them. cu130 in the logs just means the CUDA version.
An add-on
Custom Node: Every box on screen is a "node". A Custom Node is made by the community. Qwen 2.1 doesn't need any (they are native).
A popular pack
rgthree: Convenience nodes (LoRA stacker, bypass switches...).

Exercises

A reliable starting point

Get a simple image working with the official setup before trying complex things.

The Recipe

  1. Update ComfyUI: Qwen 2.1 support is recent.
  2. Open the built-in Template: Workflow Menu > Browse Templates > Search "Qwen Image 2.1" > Pick Text to Image.
  3. Place the files: The exact set listed on Slide 6, into their correct folders.
  4. Leave default settings: 1 MP, 25 steps, CFG 1, euler, simple.
  5. Run it! The first render is slow because it has to load the big files.
  6. Then, try an edit: Open the "Image Edit" template, it uses the same 3 files.

Practice

1) Create an image of a rabbit with a hat: Describe in detail (the subject's appearance, the setting, lighting, shot type, style - photo, cartoon, manga, ...). For text in the image, put the exact words "in quotes".

2) Edit this image: Ask it to transform the hat into another object using the created image as a reference. Find the correct workflow in the templates if necessary.

3) Create a prop with a transparent background: For the needs of a movie, you need a large caliber bullet hole on a brick wall. Create a small prop (512x512) with a matching transparent background.
